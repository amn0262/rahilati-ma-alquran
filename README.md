# رحلتي مع القرآن — إصدار التطوير 1.1

تطبيق ويب عربي RTL لمتابعة حفظ جزء عمّ والمراجعة والإنجازات والشهادات.

## التشغيل
- فك ضغط الملف.
- افتح `index.html` في متصفح حديث.
- للحصول على أفضل تجربة PWA والعمل دون اتصال، استضف الملفات عبر HTTPS أو شغّل خادمًا محليًا بسيطًا.

## ما تمت إضافته في هذا الإصدار
- بطاقة في الرئيسية توضّح آخر سورة ونطاق آيات سجّله الطفل، وحالة تأكيد التسميع.
- أوسمة وألقاب تتصل بتقدم الحفظ المسجل.
- مراحل شهادة: أول سورة، 10%، 25%، 50%، 75%، إتمام جزء عمّ، وشهادة الثبات والمراجعة.
- سجل للشهادات التي تم إصدارها، مع إعادة فتحها للطباعة.
- تنسيق شهادة A4 قابل للطباعة أو الحفظ PDF عبر نافذة الطباعة في المتصفح: اختر “Save as PDF / حفظ كملف PDF”.
- حفظ الشهادات ضمن بيانات التطبيق والنسخة الاحتياطية.

## تنبيه حول بيانات القرآن
هذه النسخة تتضمن أسماء سور جزء عمّ وعدد آياتها وتتبع تقدم الحفظ، ولا تتضمن نص الآيات القرآنية الكامل. لا يُولّد نص القرآن آليًا؛ ينبغي دمج نص موثوق بترخيص مناسب والتحقق منه قبل إضافة عرض الآيات.

## ملاحظات
- البيانات مخزنة محليًا في المتصفح باستخدام IndexedDB.
- لا ترسل بيانات الطفل إلى خادم خارجي.
- الشهادة تُطبع من المتصفح إلى PDF، وليست مرفق PDF مولّدًا تلقائيًا دون تدخل المستخدم.
